> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Owner request (2026-10-26, verbatim intent):** (1) add reminders; (2) music lyrics, user can turn them on/off — when on, the small notch shows only the lyric line, otherwise the song title as now; (3) when nothing is happening, show a clock instead of an empty notch; (4) move the pomodoro settings into the settings UI so the notch page only has play controls; (5) at the far right of the panel (scroll) a page of shortcut buttons — screenshot, clipboard, etc.; (6) a CLI section in the notch where commands can be typed. Every new user-facing string goes through `i18n` (both languages); every new colour comes from `theme`; new island-owned config fields go through `merge_owned`; new settings controls go into the settings window.

## Pinned decisions

| Item | Decision |
|---|---|
| Page order | Kalender, Pomodoro, Reminder, Notes, Musik, CLI, Shortcut (7 pages; Shortcut is the right-most). Page dots scale to 7. |
| Idle clock | Idle view shows the local time `HH:MM` (24 h), 13 px semibold, centred in the idle shape (shape unchanged). Redraw by a one-shot timer at the next minute boundary only while idle is visible. Setting "Jam saat kosong / Clock when idle" (toggle, default on; off = empty notch as before) in Tampilan. |
| Pomodoro panel page | Only the ring, phase label, session label, and buttons Mulai/Jeda/Lanjut, Reset, Lewati. Steppers live only in Settings → Pomodoro (already there). |
| Reminders data | `%APPDATA%\DynamicIsland\reminders.json`, `Reminder { id, text, due_unix, repeat: None/Daily/Weekly, done: bool }`, atomic save, unreadable file kept as `.bak` (same pattern as notes). |
| Reminders UI | Reminder page: upcoming (not done) sorted by due time, rows "HH:MM · text" with day label (Hari ini/Besok/date), "+N lagi" paging like notes, "+ Baru" opens the reminder editor; clicking a row edits it. Editor (same dark/light editor style): text, date picker, time picker, repeat segmented [Sekali, Harian, Mingguan], Simpan/Batal/Hapus. |
| Reminders firing | One-shot timer at the earliest due time (no polling; recomputed after any change and at day rollover). At due: sticky island notice (new `NoticeKind::Reminder { id }`, accent badge with a bell glyph, title = text, body = time) + phase-style sound; click dismisses and marks done (or schedules the next occurrence for Daily/Weekly). Reminders that fell due while the island was off fire at startup with body "Terlewat · HH:MM". Fullscreen: shown briefly like other new notices, stays sticky afterwards (Claude-waiting rules). |
| Lyrics source | LRCLIB `GET https://lrclib.net/api/get?track_name=&artist_name=&album_name=&duration=` (no key; send `User-Agent: DynamicIsland/<version> (https://github.com/hartono0297/dynamic-island)`). Use `syncedLyrics` (LRC `[mm:ss.xx] line`); no synced lyrics → no lyric view (title as usual). Fetch on the sync-style worker thread (not the UI thread), cache per track in memory (LRU 50) and on disk `%APPDATA%\DynamicIsland\lyrics-cache\<hash>.lrc` (negative results cached 24 h). Only requested when the toggle is on. |
| Lyrics position | GSMTC timeline (`GetTimelineProperties`: Position, LastUpdatedTime, EndTime) refreshed on `TimelinePropertiesChanged` and playback changes; interpolate `position + (now − last_updated)` while playing. Redraw only when the current line changes (one-shot timer to the next line's timestamp). |
| Lyrics view | Toggle "Lirik di notch / Lyrics in notch" (default off) in Settings → Tampilan and a small lyric button on the Musik page (same setting). When on and synced lyrics exist and media is playing: the compact media view becomes a wider shape (`MediaLyric`, 300 × 34) showing only the current line (12–13 px, trimmed with ellipsis, crossfade 150 ms between lines, blank instrumental lines show "♪"). Otherwise the normal compact (art + title + equalizer). Privacy note in the setting description: artist and title are sent to lrclib.net. |
| Shortcut page | 2 rows × 4 tiles (icon from Segoe Fluent Icons + label): Screenshot (`ms-screenclip:`), Clipboard (Win+V via `SendInput`), Emoji (Win+. via `SendInput`), Explorer (`explorer.exe`), Kalkulator (`calc.exe`), Task Manager (`taskmgr.exe`), Pengaturan Windows (`ms-settings:`), Kunci layar (`LockWorkStation`). Clicking a tile collapses the panel first (so the screenshot/picker targets the real foreground) then runs the action. |
| CLI page | Panel page shows a terminal-styled card: prompt `>` + the last command and the last 4 output lines (monospace "Cascadia Mono" → "Consolas"), and a primary button "Ketik perintah / Type a command"; clicking the card or button opens the CLI window. |
| CLI window | Editor-style window under the panel, 560 × 320 logical: output area (read-only multiline EDIT, monospace, dark terminal background in both modes `#0C0C0E`/text `#E6E6E6`), input line (single-line EDIT with `>` prompt). Enter runs; Up/Down history (last 100, `%APPDATA%\DynamicIsland\cli-history.txt`); Ctrl+C or a "Stop" button kills the running process; Esc closes (a running command keeps running and its output is still collected; the panel CLI card shows it). `cd <path>` / `cd` builtins handled in-app (persisted working directory, default `%USERPROFILE%`); `cls`/`clear` clears output. |
| CLI execution | Shell setting in Settings → Umum: [PowerShell | cmd] (default PowerShell). PowerShell: `powershell.exe -NoLogo -NoProfile -NonInteractive -Command "[Console]::OutputEncoding=[Text.Encoding]::UTF8; <cmd>"`; cmd: `cmd.exe /d /s /c "chcp 65001>nul & <cmd>"`. `CREATE_NO_WINDOW`, stdout+stderr piped and streamed line by line from a worker thread to the window (and the panel card), exit code line at the end. Output buffer capped at 2000 lines. No elevation. |
| Settings additions | Tampilan: "Jam saat kosong", "Lirik di notch". Umum: "Shell CLI" segmented. All live + saved (island-owned). |
| Resource | Idle unchanged except the clock's one redraw per minute. Lyrics: one redraw per line change while playing; network only on track change with lyrics on. |
