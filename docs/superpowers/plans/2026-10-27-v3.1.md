# v3.1: lirik, CLI folder, judul tegak, Sistem & deep clean, Clipboard, Screenshot — Rencana

**Permintaan pemilik (2026-10-27):** (1) lirik di notch jangan terpotong; (2) CLI otomatis di folder yang terakhir dibuka; (3) judul jangan italic; (4) monitor CPU/RAM/disk + deep clean (terinspirasi [tw93/mole](https://github.com/tw93/mole)); (5) clipboard sendiri di notch; (6) screenshot dengan preview, bisa salin atau hapus di notch. Semua sudah dibahas lewat PDF dan diputuskan; rencana ini untuk dijalankan nanti, mungkin di PC lain.

**Referensi visual** (sumber kebenaran tampilan, di `docs/design/`):

| File | Isi |
|---|---|
| `brainstorm-v3.1.pdf` / `.html` | Semua pilihan per ide (A/B/C) |
| `keputusan-v3.1.pdf` / `.html` | Mockup final untuk ide yang disetujui + analisis Mole |
| `deepclean-opsi-d.pdf` / `.html` | Deep clean dua mode (opsi D) |
| `rencana-v3.1.pdf` | Rencana ini dalam bentuk visual |

Warna, ukuran dan ikon tetap token Studio v3 (`studio-ui.html`, `docs/memory/v3-studio-overview.md`).

## Cara menjalankan

Setiap **run** dijalankan dengan workflow `build` (lihat `AGENTS.md`), berurutan; run berikutnya baru dimulai setelah run sebelumnya hijau dan ter-push. Teks *args* di tiap run adalah request untuk workflow.

**Sebelum Run 1 (Fase 0):** `git pull`; di PC baru, jalankan ulang preflight `AGENTS.md` (abaikan `.claude/preflight.done`); pastikan Rust stable (MSVC) + VS 2022 Build Tools (C++) terpasang dan `cargo test --locked` hijau.

## Fase 1 — Tampilan

### Run 1 · Judul tegak (DM Sans 600) — *args:*
> Ganti semua Fraunces Italic dengan DM Sans 600 sesuai Run 1 di docs/superpowers/plans/2026-10-27-v3.1.md.

- Semua tempat Fraunces Italic: judul halaman panel, judul lagu, jam besar Pomodoro, jam di notch, judul Pengaturan & editor, teks lirik di notch → DM Sans 600, letter-spacing −2,5%, angka tabular tetap (lihat [[studio-tabular-figures-word-gaps]]).
- `src/ui/fonts.rs`, `render.rs`, `render_panel.rs`, `panel_layout.rs`, `geometry.rs`, `settings_controls.rs`, `settings_layout.rs`, `editor_layout.rs`.
- Keluarkan Fraunces: `app.rc` RCDATA 201/202, `assets/fonts/Fraunces-*`, `scripts/make-fonts.ps1`, kredit README; perbarui catatan `studio-font-sources`.
- **Selesai kalau:** tidak ada referensi "Fraunces" di `src/`; exe lebih kecil; screenshot demo tanpa italic.

### Run 2 · Lirik melebar — *args:*
> Buat notch lirik melebar mengikuti panjang baris sesuai Run 2 di rencana v3.1.

- `geometry.rs`: `ShapeKind::MediaLyric` tidak lagi tetap 300 × 34; lebar = layout DirectWrite baris aktif + robot + padding, dibatasi min 220 dan maks min(560, 45% lebar layar).
- Animasi lebar 180 ms lewat pegas notch yang ada; **tidak menyusut** kalau baris baru < 40 px lebih pendek.
- Lebih dari maks: diam 1 dtk, lalu bergeser pelan ke ujung baris; ujung kanan memudar. Baris "♪" = lebar minimum. Redraw hanya selama bergeser.
- **Selesai kalau:** test geometri (batas, histeresis, maks per lebar layar); tidak ada "…" di baris yang muat 560 px.

## Fase 2 — CLI

### Run 3 · CLI ikut folder Explorer + menu folder — *args:*
> CLI pindah ke folder Explorer terakhir dan dapat menu folder sesuai Run 3 di rencana v3.1.

- Saat halaman CLI dibuka **dan tidak ada perintah berjalan**: baca jendela File Explorer yang terakhir aktif lewat `IShellWindows` (COM, sekali saat dibuka), pindah ke foldernya; chip "dari Explorer" + satu baris info di output. Tidak ada Explorer → tetap `cli-cwd.txt`.
- Klik chip folder → menu: Explorer terbuka (urut terakhir aktif), Favorit (bintang, klik kanan lepas), Terakhir dipakai (5). Data di `%APPDATA%\DynamicIsland\` (`cli-favorites.txt`, `cli-recent.txt`), tulis atomik seperti `cli-cwd.txt`.
- Pengaturan → Umum: "Folder awal CLI" = Ikuti Explorer / Folder terakhir.
- Hormati fokus keyboard yang sudah ada ([[cli-panel-keyboard-focus]]); menu tidak boleh mengambil foreground.
- **Selesai kalau:** test penyimpanan favorit/riwayat & pemilihan folder; tidak pernah pindah folder di tengah perintah.

## Fase 3 — Sistem

### Run 4 · Halaman Sistem (monitor) — *args:*
> Tambah halaman panel Sistem untuk CPU, RAM, disk dan proses teratas sesuai Run 4 di rencana v3.1.

- Modul baru (mis. `src/system.rs`): CPU dari `GetSystemTimes`, RAM `GlobalMemoryStatusEx`, disk per drive `GetDiskFreeSpaceExW`, 3 proses teratas dari snapshot proses (CPU % & memori). Fungsi hitung murni + test.
- `Page::System` setelah Clipboard (lihat Run 9); cincin CPU + grafik 60 dtk, bar RAM & disk (oker di bawah batas), uptime, tombol "Bersihkan" (Run 5–6).
- Update tiap 2 dtk hanya saat halaman terlihat; saat tertutup cek disk & RAM tiap 5 mnt untuk peringatan (notice dengan robot lesu, sekali per lintasan batas, seperti baterai).
- Klik disk → Explorer di drive; klik proses → Task Manager. Pengaturan → Umum: batas disk & RAM.
- **Selesai kalau:** idle tetap hemat (tanpa redraw saat tertutup); test peringatan sekali-lewat.

### Run 5 · Deep clean mode "Pilih sendiri" — *args:*
> Bangun pembersih island (mode Pilih sendiri) sesuai Run 5 di rencana v3.1 dan docs/design/deepclean-opsi-d.pdf.

- Modul baru (mis. `src/clean.rs`): kategori — File sementara & log (> 7 hari), Cache browser (lewati browser yang terbuka), Cache aplikasi (VS Code, Teams, Discord, Spotify, Zoom), Cache developer (npm, pip, NuGet, Go, Cargo), Cache Autodesk & Adobe, Installer lama di Downloads (> 30 hari), Sisa Windows Update (admin).
- Daftar lokasi mengacu pada Mole Windows (`lib/clean/*.ps1`, MIT): **data saja**, tulis ulang di Rust, cantumkan kredit + teks lisensi MIT di README / NOTICE. Jangan salin kode Mole macOS (GPL).
- Pindai di thread latar → ukuran per kategori. Hapus: cache permanen; file pengguna (Downloads) ke Recycle Bin (`IFileOperation` dengan undo). File terkunci dilewati dan dilaporkan.
- Kategori admin: jalankan exe sendiri dengan argumen khusus lewat `runas` (UAC), bukan seluruh app sebagai admin.
- Panel "Bersihkan" (dari halaman Sistem) dengan segmen mode; tombol menampilkan total yang dicentang; konfirmasi di tombol. Hasil = selisih sisa disk yang diukur island; notice selesai.
- **Selesai kalau:** test pemilihan lokasi (umur file, pengecualian browser terbuka), pemindaian di folder sementara buatan test, tidak ada hapus tanpa konfirmasi.

### Run 6 · Deep clean mode "Otomatis · Mole" — *args:*
> Tambah mode Otomatis dengan Mole di halaman Bersihkan sesuai Run 6 di rencana v3.1 dan deepclean-opsi-d.pdf.

- Deteksi Mole: `%LOCALAPPDATA%\Mole\mole.ps1` atau `mo` di PATH; baca `VERSION`. Tidak terpasang → kartu "Cara memasang" (tautan README Mole Windows), tanpa memasang sendiri.
- Alur: **pratinjau** `powershell -NoProfile -ExecutionPolicy Bypass -File mole.ps1 clean --dry-run` (proses tersembunyi, seperti CLI) → parse baris "(N items, X MB dry)" ke 4 grup → konfirmasi "Yakin? Hapus permanen" → `clean` → log di panel (kode ANSI dibuang, baris tabel internal disaring) → hasil = selisih sisa disk.
- Format tidak terbaca → "lihat log", jangan menebak angka. Ringkasan Mole tidak dipakai (diketahui salah, lihat keputusan-v3.1 hal. 9).
- Opsi: "+ Sistem (admin)" (tampil, tidak dicentang; perlu PowerShell admin via `runas`), "+ Media game > 90 hari". "Lindungi folder…" → `mo clean --whitelist`. Saat pertama pakai, tambahkan cache Cargo & Autodesk ke whitelist Mole kalau belum ada (bisa dimatikan).
- Chip "Eksperimental"; versi ≠ 1.30.x → peringatan, tetap boleh. Status di notch: berpikir saat jalan, senang/lesu saat selesai/gagal.
- **Selesai kalau:** test parser pada contoh output nyata (termasuk baris rusak), test ANSI strip; Mole tidak pernah jalan tanpa pratinjau + konfirmasi.

## Fase 4 — Clipboard & Screenshot

### Run 7 · Clipboard sendiri — *args:*
> Tambah riwayat clipboard dan halaman panel Clipboard sesuai Run 7 di rencana v3.1.

- Modul baru (mis. `src/clipboard.rs`): `AddClipboardFormatListener` + `WM_CLIPBOARDUPDATE`; 50 item; jenis: teks, tautan, kode, warna hex, gambar (thumbnail), file.
- **Lewati** isi dari password manager: format `ExcludeClipboardContentFromMonitorProcessing`, `CanIncludeInClipboardHistory` = 0, dan sejenisnya. Abaikan perubahan yang dibuat island sendiri.
- Simpan terenkripsi DPAPI (`clipboard-history.bin`), gambar dikecilkan; opsi hanya di memori.
- Halaman `Page::Clipboard`: cari, kartu 2 kolom, sematkan, hapus, salin sebagai teks biasa; ↑↓ / Enter. Tombol Clipboard di Shortcuts membuka halaman ini (bukan Win+V).
- Pengaturan (bagian baru "Clipboard"): aktif, jumlah item, simpan setelah restart, hapus saat dikunci, pintasan (**default tidak ada**; jangan tawarkan Ctrl+Shift+V), "Disalin" untuk semua salinan (default mati).
- **Selesai kalau:** test deteksi jenis, batas 50 + sematan, pengecualian password manager, round-trip file terenkripsi.

### Run 8 · Screenshot dengan preview — *args:*
> Tambah preview screenshot di notch dengan Salin lagi, Simpan, Hapus sesuai Run 8 di rencana v3.1.

- Tombol Screenshot tetap `ms-screenclip:`. Deteksi screenshot baru: gambar baru di clipboard (dari Run 7) + file baru di folder Screenshots (`Pictures\Screenshots`, lokasi dari Known Folder) dalam beberapa detik — juga untuk PrtSc dan Win+Shift+S.
- Notice besar: thumbnail, ukuran, Salin lagi / Simpan / Hapus. Hapus = hapus file + kosongkan clipboard bila masih gambar yang sama. Klik gambar = buka file (aplikasi bawaan / Snipping Tool).
- Diabaikan 8 dtk → Simpan. Pengaturan: preview aktif, jika diabaikan (Simpan/Hapus), lama tampil.
- Screenshot ikut masuk riwayat Clipboard sebagai kartu gambar.
- **Selesai kalau:** test pencocokan file ↔ gambar clipboard; tidak ada file terhapus tanpa klik Hapus.

## Risiko

| Risiko | Penanganan |
|---|---|
| Output Mole berubah / salah | Parse per baris saja, hasil diukur island, fallback "lihat log" |
| Hapus data penting | Pratinjau + konfirmasi; file pengguna ke Recycle Bin; whitelist Cargo & Autodesk di mode Mole |
| Clipboard menyimpan rahasia | Lewati format password manager; terenkripsi DPAPI; opsi hanya memori |
| Pintasan bentrok | Tidak ada pintasan bawaan; Ctrl+Shift+V tidak ditawarkan |
| Monitor memboroskan daya | Redraw hanya saat halaman Sistem terlihat; cek latar tiap 5 mnt |
| COM Explorer lambat | Dibaca sekali saat halaman CLI dibuka, di luar jalur gambar |
| Admin (Windows Update, Mole --system) | Proses terpisah via UAC, bukan seluruh app |
