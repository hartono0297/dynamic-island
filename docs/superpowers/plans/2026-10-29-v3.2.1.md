# Rencana v3.2.1 — perbaikan setelah uji 3.2.0

Sumber: delapan catatan dari pengguna setelah memasang 3.2.0. Dikerjakan
langsung di sesi utama (workflow `build` mati), satu commit per kelompok,
tes hijau tiap kali, blind review di akhir, lalu rilis.

## Jawaban jujur untuk dua pertanyaan

- **"Di belakang jendela" tidak dikerjakan di 3.2.0.** Itu sengaja dilewati
  (eksperimen opsional di rencana, berisiko berebut z-order dengan layar
  penuh). Sekarang dikerjakan sebagai setelan, **mati bawaan**.
- **Pencarian sudah ada**, tetapi hotkey-nya *mati bawaan* (Pengaturan →
  Umum → Pencarian) sehingga tampak tidak ada. Sekarang aktif bawaan dan ada
  pintu masuk lain.

## Kelompok

### A · Musik dan clipboard
1. **Clipboard: tombol Pin / Hapus** hanya muncul di kartu pertama → cari
   sebab (kartu terpilih? hover?) dan perbaiki supaya muncul di kartu yang
   disorot/dipilih mana pun.
2. **Volume dengan scroll** saat musik diputar dan pointer ada di notch
   (tampilan musik ringkas/lirik): roda mengubah volume lagu (±2% per
   takik), tanpa mengganti halaman. Ada umpan balik singkat.
3. **Lirik masih kadang terlalu cepat**: telaah `lyrics.rs`/`app.rs` (lookahead
   150 ms, resync, offset) dan perbaiki; bawaan lebih aman (tidak terlalu
   cepat), tes baru.

### B · File shelf
4. **Buka otomatis saat file diseret ke notch**: periksa kenapa tidak terbuka
   (jendela layered, target drop hanya di piksel tergambar, pulau idle kecil)
   dan perbaiki; UI shelf dirapikan (kartu, jarak, ikon, status kosong).

### C · Perilaku jendela
5. **Di belakang jendela** (setelan, mati bawaan): pulau di lapisan bawah,
   naik saat kursor di strip tepi atas, turun lagi; notif tetap muncul di
   atas; hormati layar penuh.
6. **Pencarian**: hotkey bawaan Ctrl+Alt+Space, entri di menu tray, dan
   catatan di Pengaturan jika hotkey gagal didaftarkan.

### D · System dan logo
7. **Halaman System lebih mulus dan tetap enteng**: sampling dan animasi
   (ring, bar) diperhalus tanpa menaikkan beban saat panel tertutup.
8. **Logo baru** (kepala kucing hitam-oranye seperti di Pengaturan) untuk
   `assets/icon.ico`, `logo-256.png`, `logo.svg`, ikon exe/tray, README.

## Penutup
- Blind review dari agen yang tidak melihat kesimpulan kita, lalu cek tes,
  build rilis dan screenshot.
- README dan catatan Obsidian (`docs/memory/`) diperbarui.
- Commit, push `main`, tag `v3.2.1`, pastikan rilis dan `install.ps1` memasang
  versi terbaru.
