# v3.0 "Studio": redesign total, robot Bata, editor baru, CLI di panel — Rencana

**Permintaan pemilik (2026-10-26):** ganti tampilan app secara total (warna, font, logo, ikon) memakai arah **Studio**; logo **Bata**; robot asisten **Bata** di notch (tanpa telinga dan antena); perbaiki editor **acara** dan **pengingat** yang jelek; **CLI pindah ke dalam panel**, tanpa jendela popup. Semua dikumpulkan jadi satu rencana untuk dijalankan nanti.

**Referensi visual** (sumber kebenaran untuk tampilan, di `docs/design/`):

| File | Isi |
|---|---|
| `studio-ui.pdf` / `.html` | Token, logo, semua status notch, 7 halaman panel, editor, pengaturan |
| `studio-robot.pdf` / `.html` | Robot Bata: bentuk, 10 ekspresi, di notch, perilaku & pengaturan |
| `editor-acara.pdf` / `.html` | Kenapa editor acara jelek + desain baru |
| `pengingat-cli.pdf` / `.html` | Editor pengingat baru + CLI di panel |
| `rencana-v3.pdf` | Rencana ini dalam bentuk visual |

Nilai warna, ukuran dan geometri ikon/robot diambil langsung dari file `.html` di atas (lihat fungsi `icon()`, `robot()`, `logo()` dan variabel CSS).

## Cara menjalankan

Setiap **run** di bawah dijalankan dengan workflow `build` (lihat `AGENTS.md`), satu per satu, berurutan. Isi kolom *args* adalah request untuk run itu. Run berikutnya baru dimulai setelah run sebelumnya ter-push ke `main` dan hijau.

**Syarat sebelum Run 1 (Fase 0):**
- Pasang Rust: `winget install Rustlang.Rustup`, lalu `rustup toolchain install stable --profile minimal` dan Visual Studio Build Tools (C++). Saat ini `cargo` belum ada di PC ini.
- Pastikan `cargo test --locked` hijau di `main` sebagai titik awal.
- Commit semua file di `docs/design/` dan rencana ini.

## Fase 1 — Fondasi visual

### Run 1 · Warna Studio + logo Bata — *args:*
> Ganti palet ke Studio dan logo ke Bata sesuai docs/superpowers/plans/2026-10-26-v3-studio.md Fase 1 Run 1.

- `src/theme.rs`: `Accent` → Terracotta `#E2683C`, Sage `#9DB59A`, Ochre `#D9A441`, Clay `#C9826B`, Olive `#A3A55A`, Plum `#B07A9A` (default Terracotta). `Surface` → Espresso `#17120F` (default), Graphite (satu tingkat lebih terang, mis. `#221B17`). Palet island: raised `#241D18`, raised_hi `#3A2F27`, track `#332A23`, column `#1D1713`, dot_off `#4A3E35`, text `#F4EDE4`. `WindowPalette` terang: bg `#F4EEE6`, card `#FFFBF5`, text `#221A14`, secondary `#7A6B5D`, aksen `#C9542B`, pilih `#EADFD1`; gelap: bg `#1E1814`, card `#272019`, field `#2C241D`, text `#F4EDE4`, secondary `#A89A8B`, aksen `#E2683C`. `TERMINAL_BG` `#0F0C0A`.
- Alias nama lama di `named_enum` (lihat tabel di atas) supaya `config.json` lama tidak kembali ke default secara acak.
- Perbarui test yang mengunci hex; test kontras yang ada harus tetap lulus (ink di aksen ≥ 3:1, teks ≥ 7:1, secondary ≥ 4,5:1).
- Logo: `assets/logo.svg`, `scripts/make-icon.ps1` (bentuk yang sama), regenerasi `assets/icon.ico` dan `assets/logo-256.png`, ikon tray/jendela di `src/ui/app_icon.rs`.
- **Selesai kalau:** semua test hijau; app memakai warna baru; ikon tray 16 px terbaca di taskbar gelap dan terang.

### Run 2 · Font tertanam — *args:*
> Tanam font Fraunces, DM Sans dan DM Mono sesuai Fase 1 Run 2 di rencana v3-studio.

- `assets/fonts/`: subset Latin Fraunces Italic (400/500), DM Sans (400/500/600), DM Mono (400/500) + `OFL.txt`. Kredit di README.
- DirectWrite: muat sebagai koleksi font in-memory (`IDWriteFactory5` + `IDWriteInMemoryFontFileLoader`) di tempat font dibuat (`render.rs`, `render_panel.rs`, `settings_controls.rs`). Jendela GDI yang tersisa: `AddFontMemResourceEx`.
- Kalau gagal dimuat: kembali ke Segoe UI Variable / Cascadia Mono, tanpa crash.
- Skala: jam besar Fraunces It 48, judul Fraunces It 20, teks DM Sans 12, keterangan DM Sans 10,5, kode DM Mono 11; angka memakai tabular figures.
- **Selesai kalau:** exe naik ≤ 400 KB; test baru untuk fallback; screenshot demo memakai font baru.

### Run 3 · Set ikon sendiri — *args:*
> Ganti semua ikon Segoe Fluent dengan set ikon Studio sesuai Fase 1 Run 3 di rencana v3-studio.

- Modul baru `src/ui/icons.rs`: enum `Icon` + path 24-grid (salin geometri dari `icon()` di `docs/design/studio-ui.html`), digambar sebagai `ID2D1PathGeometry`, garis 1,5, ujung bulat, isian aksen 38% untuk bentuk tertutup.
- Ganti pemakaian glyph di `render.rs`, `render_panel.rs`, `settings_controls.rs`, dan `shortcuts.rs` (`glyph()` → `Icon`).
- **Selesai kalau:** tidak ada lagi referensi ke "Segoe Fluent Icons"/"Segoe MDL2 Assets"; test `shortcuts` diperbarui (ikon unik per tombol).

## Fase 3 — Editor baru

### Run 5 · Kerangka editor + editor acara — *args:*
> Bangun ulang editor acara tanpa kontrol tanggal Windows sesuai Fase 3 Run 5 di rencana v3-studio dan docs/design/editor-acara.pdf.

- Kerangka bersama di `editor.rs`: jendela tanpa bingkai (sudut bulat Win11), header/tombol tutup/footer/chip/toggle/segmen digambar Direct2D. Kotak teks tetap `EDIT` (IME, paste, undo), tanpa border, warna token.
- Hapus `DATETIMEPICK_CLASSW`, `paint_themed`, `tone`.
- Popover (jendela kecil tanpa bingkai): kalender (memakai ulang gambar grid bulan dari panel) dan daftar jam per 15 menit dengan durasi; jam bisa diketik.
- Editor acara: judul besar, chip tanggal + pintasan (Hari ini, Besok, nama hari, Minggu depan), chip jam mulai → selesai + durasi, toggle Sepanjang hari (menyembunyikan jam), catatan, akun Google di footer. Simpan nonaktif sampai judul diisi; jam selesai ≤ mulai → pesan error satu baris.
- Format tanggal dari `i18n.rs`, bukan dari Windows.
- Keyboard: Tab antar field, panah di kalender, Enter memilih, Esc menutup popover lalu editor.
- Editor catatan memakai kerangka yang sama.
- **Selesai kalau:** tidak ada lagi teks berwarna pelangi atau format "10/26/2026"; test untuk validasi jam, format tanggal ID/EN, dan simpan.

### Run 6 · Editor pengingat — *args:*
> Bangun ulang editor pengingat sesuai Fase 3 Run 6 di rencana v3-studio dan docs/design/pengingat-cli.pdf hal. 1–2.

- Pakai kerangka & popover dari Run 5. Teks besar, chip tanggal & jam (tanggal lewat diredupkan; saran pagi/siang/sore/malam), segmen Sekali/Harian/Mingguan, kalimat ringkasan ("Sekali, hari ini jam 16:30 · 4 jam lagi"), Hapus di kiri hanya saat mengedit.
- **Selesai kalau:** pengingat lama tetap bisa dibuka & disimpan; test ringkasan.

### Run 6b · (fitur baru) Mingguan pilih hari + pintasan waktu — *args:*
> Tambah pilihan beberapa hari untuk pengingat Mingguan dan pintasan waktu sesuai Run 6b di rencana v3-studio.

- `reminders.rs`: `Reminder` mendapat daftar hari (mis. `days: Vec<Weekday>`), opsional di JSON; pengingat lama (tanpa daftar) = hari dari tanggal awal. `next_due`/`advance_in` menghitung hari berikutnya dalam daftar; test termasuk DST.
- Editor: chip hari S S R K J S M (boleh lebih dari satu); pintasan 30 mnt lagi, 1 jam lagi, Nanti malam (20:00), Besok pagi (08:00).
- **Selesai kalau:** test round-trip `reminders.json` lama & baru; test jadwal multi-hari.

## Fase 4 — CLI di panel

### Run 7 · CLI di dalam panel — *args:*
> Pindahkan CLI ke dalam halaman panel dan hapus jendela CLI sesuai Fase 4 Run 7 di rencana v3-studio dan docs/design/pengingat-cli.pdf hal. 3–6.

- Fokus keyboard: island dibuat dengan `WS_EX_NOACTIVATE` (`src/ui/window.rs`). Saat input CLI dipakai, island boleh aktif; dilepas lagi saat Esc/klik di luar. Selama input aktif, panel tidak menutup saat mouse keluar (`state.rs`).
- Input: satu `EDIT` tersembunyi untuk IME/paste/undo, digambar di panel. Enter jalankan, ↑↓ riwayat, Tab terima saran, Ctrl+C stop (atau salin kalau ada seleksi), Esc keluar.
- Output: mengalir dari bawah, DM Mono; roda mouse di area output menggulir output (bukan pindah halaman); PageUp/PageDown. Chip status: folder, shell, "Berjalan · 0:42" + Stop, hasil "selesai · 2,1 dtk" (sage) / "exit 1" (merah lembut).
- Saran riwayat di atas input. `cd` dan `cls` tetap jalan (`cli.rs` tidak berubah perilakunya).
- Tombol perbesar: panel 560 × 440, kembali kecil saat panel ditutup.
- Hapus `src/ui/cli_window.rs`.
- **Selesai kalau:** perintah tetap jalan saat panel ditutup; test state untuk kunci panel & scroll; tidak ada jendela CLI lagi.

## Fase 5 — Robot Bata

### Run 8 · Robot di notch — *args:*
> Tambahkan robot Bata di notch sesuai Fase 5 Run 8 di rencana v3-studio dan docs/design/studio-robot.pdf.

- `src/ui/robot.rs`: kepala (rect 52×46 r18 terakota), visor (40×22 r11 espresso), mata krem; kedip + 10 ekspresi (diam, senang, fokus, mendengar, bernyanyi, waspada, berpikir, tidur, lesu, menyapa) dari `robot()` di `docs/design/studio-robot.html`. Ukuran 20–48 px.
- Kapan muncul: jam kosong (diam/tidur), Pomodoro (fokus), musik (mendengar), lirik (bernyanyi), pengingat (waspada), fase selesai (senang), Claude bekerja (berpikir) / butuh kamu (waspada), baterai (lesu), CLI berjalan/selesai/gagal (berpikir/senang/lesu). **Tidak** untuk notifikasi aplikasi lain.
- Animasi lewat `frame_clock.rs`: kedip acak 4–7 dtk (120 ms), hover senang + naik 2 px, waspada memantul 2×, tidur setelah N menit tanpa aktivitas. Mode Hemat: tanpa gerak.
- Sapaan pagi: sekali sehari saat layar pertama aktif, "Selamat pagi · X acara dan Y pengingat hari ini", hilang setelah 4 dtk.
- Pengaturan → Tampilan: Asisten di notch, Animasi (Penuh/Hemat/Mati), Tidur setelah (menit), Sapaan pagi. Field baru di `config.rs` dengan default.
- **Selesai kalau:** idle tetap hemat (hanya redraw kedip singkat); test untuk pemilihan ekspresi dan jadwal tidur; lebar notch disesuaikan di `geometry.rs`.

## Risiko

| Risiko | Penanganan |
|---|---|
| Rust belum terpasang | Fase 0 wajib dulu |
| Fokus keyboard di island (CLI) mengganggu aplikasi lain | Fokus hanya saat input dipakai; lepas di Esc/klik luar; test manual di app layar penuh |
| Ukuran exe naik karena font | Subset Latin, batas 400 KB |
| Fraunces Italic kurang terbaca di ukuran kecil | Hanya untuk judul ≥ 16 px dan jam; teks kecil tetap DM Sans |
| Data pengingat (Run 6b) | Field opsional + test file lama |
| Agen workflow tidak bisa "melihat" UI | Check memakai screenshot `demo.rs` dibandingkan dengan PDF desain |
